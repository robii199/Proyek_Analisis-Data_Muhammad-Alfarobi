# Bike Sharing Analysis Dashboard

## Project Overview
Proyek ini menganalisis data penyewaan sepeda (Bike Sharing) tahun 2011–2012.
Fokus analisis:
- Pengaruh musim terhadap jumlah penyewaan sepeda
- Pengaruh kondisi cuaca terhadap jumlah penyewaan sepeda

## Setup Environment

## 1. Clone Repository
  - git clone https://github.com/robii199/Proyek_Analisis-Data_Coding-Camp.git
  - cd Proyek_Analisis-Data_Coding-Camp
## 2. Buat Virtual Environment
python -m venv venv
## 3. Aktifkan Virtual Environment
- Windows
  - venv\Scripts\activate
- Mac / Linux
  - source venv/bin/activate
## 4. Install Dependencies
pip install -r requirements.txt
## 5. requirements.txt
  - streamlit==1.56.0
  - pandas==2.3.3
  - numpy==2.2.6
  - matplotlib==3.10.9
  - seaborn==0.13.2
## 6. Run Dashboard
streamlit run dashboard.py
## 7. Akses Dashboard
  - Jika berjalan lokal:
    - http://localhost:8501
  - Secara online
    - https://submission-analysis-data-muhammad-alfarobi.streamlit.app/
